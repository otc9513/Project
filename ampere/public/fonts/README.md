# خط PDF العربي (المرحلة 6)

ضع هنا ملف خط عربي حقيقي باسم **`arabic-regular.ttf`** (مثال: خط Amiri أو
Noto Naskh Arabic - كلاهما مرخّص Open Font License ومناسب للاستخدام
التجاري) لتفعيل تصدير PDF عربي متصل الحروف بجودة إنتاجية.

بمجرد وجود الملف هنا، يعمل التشكيل العربي (Reshaping + Bidi) تلقائيًا
دون أي تعديل كود إضافي - راجع:
- `src/features/reports/lib/arabic-shaping.ts`
- `src/features/reports/lib/pdf-export.ts`

طالما هذا الملف غير موجود، يبقى تصدير PDF إنجليزيًا فقط (سلوك احتياطي
آمن، لا كسر لأي وظيفة موجودة)، مع توجيه المستخدم لتصدير Excel كبديل
عربي كامل فوري.
